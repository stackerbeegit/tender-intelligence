# Connectors

Empty placeholder package for Sprint 2. Will contain `base/base_connector.py`
(the `discover/fetch_tender/fetch_documents/parse/normalise` interface) plus
one isolated subpackage per source (`gem/`, `cppp/`, `state/`, ...).

No portal-specific connector is implemented yet. Before one is added, that
source's terms of use / robots policy / official API availability must be
documented in the `sources.terms_access_notes` column — see
`docs/architecture.md` §4 and Rules 11/12 in the project brief.
